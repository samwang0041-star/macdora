# CleanMyMac 设计研究

观察对象为本机 CleanMyMac 5.7.2（arm64），日期为 2026-10-26。研究的目标是理解其视觉层级、材质与交互反馈，并转化为适合 Macdora 的规则。Macdora 的生产参数、素材和行为以本目录 README 与项目源码为准。

## 研究方法与证据

先实际观察“智能呵护”和“应用程序”页面，再从已安装软件包读取 Info.plist、框架结构、资源清单和 Mach-O 符号。使用本机 REA CLI 进行包清点，以已有命令行工具核对 arm64 反汇编。没有执行扫描、清理、购买或权限申请。

颜色不能按相邻函数的排列推断归属。本轮逐项跟踪公开 Swift getter、它实际传入的初始化函数地址，以及该函数调用颜色构造器时的整数与 alpha 输入。字号/字重同样以初始化项中的数值和系统字重符号为准。可机器核查的结果保存在 [cleanmymac-5.7.2.json](references/cleanmymac-5.7.2.json)，包括来源二进制摘要、函数地址、分类和未知项；原始包清点、反汇编和现场截图留在本地私有证据中。

| --- | --- | --- |
| 命名颜色 | 71 个 getter 中，30 个已追到构造输入 | RGB 整数和 alpha 已核对，颜色空间与全部运行时用法未确认 |

## 具体学到了什么

**质感来自有层次的状态。** 例如 `Button.ghostDarkHover` 与 `Button.ghostDarkPressed` 使用相同的 `#cdc5e0` 构造输入，alpha 分别是 0.24 和 0.48。悬停和按下通过覆盖强度区分，而不是每个状态再换一种高饱和颜色。材质、边缘线和前后层共同建立空间感。

**色彩承担明确角色。** 已核对的输入包含粉色、绿色、黄色、材质色与局部装饰色。`buttonPaid` 是 `#ffd02c`；`pink1` 是 `#cc31b2`；`green1` 是 `#6dff73`。这些名称帮助理解语义分工，不能据此把整套产品概括成某一条蓝紫渐变。Macdora 使用自己的蓝色体系。

**字阶围绕任务和页面空间展开。** 初始化项包含 44、40、36、32、24、20、18、16、14、12、11、10pt 等字号。名称和实际系统字重并不一一同名，例如 `regular44` 实际使用 `_NSFontWeightLight`，`semibold40` 实际使用 `_NSFontWeightMedium`。只有检查初始化输入才能准确描述它们；不能从命名推断字重、行高或 tracking。

**主视觉与工具控件各有分工。** 实际页面把立体主视觉、固定导航、简短说明和当前主操作放在不同层级。软件包存在独立的 DesignSystem、SharedUI、NavigationUI 与背景框架，也包含图像序列与局部 Rive 资源。资源的存在只能证明实现有这些手段，不能证明某个当前页面正在使用哪一条渲染路径。

**动效由状态触发。** 静态默认值提供了 0.2s 的局部反馈、0.5s 的背景变化和 2s 的轨道周期等不同时间尺度。这给 Macdora 的启发是按用途分配动效；本轮没有完整恢复 CleanMyMac 的播放调度、性能预算或后台策略。

## 转化到 Macdora

| 研究线索 | Macdora 的实现与规则 |
| --- | --- |
| 固定导航与分层工作区 | 深蓝侧栏、清楚的选中底板、单一固定标题区；操作跟随当前页面 |
| 立体主视觉 | 使用自绘 CALayer 平板、透视、高光和投影；品牌、图形与代码由本项目独立实现 |
| 半透明材质与状态覆盖 | 用语义颜色维护卡片、次级面、悬停和按下；文字使用独立实色，保证可读性 |
| 面向任务的字阶 | 结合管理端密度采用 21pt 页面标题、15pt 状态标题、14.5pt 列表名与 12.5pt 正文 |
| 按用途划分时间尺度 | 切页 200ms、主视觉入场 450ms、真实忙碌光晕 480ms 且最多两轮 |
| 状态与下一步相连 | 下载才显示实测进度；等待、失败、未采样和未检查分别给出真实文案 |

原生动画最终状态先写入 model layer。系统减少动态效果、应用退出前台、窗口隐藏、遮挡或最小化时暂停装饰动效。主题切换同步管理端、应用窗口与缓存的定位搜索结果，保留首帧等待时的透明遮罩、输入门控和当前搜索状态。这些是 Macdora 本轮的产品决策与实现，不能归为已经逆向确认的 CleanMyMac 行为。

## 后续维护边界

当前未恢复的内容包括另外 41 个命名颜色、颜色空间、完整使用位置、全局间距体系、完整阴影、行高与字距，以及每种转场的运行时覆盖、曲线和中断行为。升级参考软件版本时先重新校验二进制与 getter 链路，再更新研究文件；不要把旧地址直接用于另一版本。

本目录不打包 CleanMyMac 的图片、动画、字体或实现代码。研究 JSON 不参与 Macdora 的渲染。修改 Macdora 样式应从现有 AppKit 公共组件与语义 token 入手，再运行本目录的导出脚本同步文档。
