# 系统助手（agent.mika）

Macdora 的原生系统级 App 操作助手。**不在 Android 环境里安装任何应用**：宿主服务在
guest 内启动一个系统级显示会话，通过 adb 的系统通道（截图、输入、启动、输入法提交）
直接操作任意应用；推理循环与模型调用全部在 Mac 侧完成。

## 使用

1. 启用插件后，宿主服务会自动准备环境；打开工作台预览或开始任务时按需创建一块
   不可见的后台显示，连续 5 分钟没有任务或预览活动后自动释放。
2. 在 Mac 上启动 Magpie。工作台自动连接本机 `http://127.0.0.1:3425/v1`，从 Magpie
   的模型目录里选择支持截图输入与工具调用的模型，不需要填写地址或密钥。需要换模型时
   在下拉框里选择即可；支持思考的模型会同时显示「思考等级」，默认由 Magpie 决定。
3. 在任务框输入目标（例如「给微信文件传输助手发消息：测试」），助手在后台显示上
   逐步操作，右侧观察窗实时显示画面，不影响你正在使用的前台窗口。
   同一时间只执行一个任务，避免多条任务争用同一块后台显示。

## 实现要点

- 后台显示：宿主在 guest 内启动 scrcpy 会话创建虚拟显示（`scrcpy-server-assistant.jar`），
  视频流以 10 FPS 维持并丢弃，显示只服务本插件；空闲时释放，不长期占用编码器。
- 观察与操作：`screencap`（按 SurfaceFlinger 显示标识截图）、`input -d`
  （点击/滑动/按键）、`am start --display`（启动应用到后台显示）。
- 中文输入：复用 macdora 的 DirectInput 输入法通道，按需建立一次性连接提交文字。
- 模型：本机 Magpie 网关的 OpenAI 兼容 `chat/completions`，工具调用驱动上述系统动作；
  模型与上游凭据都由 Magpie 管理。选择思考等级后，请求会带上对应的
  `reasoning_effort`。

## 已知边界（Limitations）

- 需要模型支持图片输入（每步发送当前屏幕截图）。
- Magpie 未运行或没有可用的视觉模型时，任务会提示网关不可用。
- 登录、验证码与支付步骤会交回用户处理。
- 后台显示按需创建并在空闲 5 分钟后释放；停用插件会立即释放该显示。
